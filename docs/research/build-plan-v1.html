What you are building

Your car becomes a living digital organism. Seven intelligence layers, running entirely on $35 hardware and your spare phone.

The Core Vision

A Tron-style 3D model of your Honda Accord on the Pixel 6 Pro where every subsystem glows, pulses, and changes color based on live vehicle data. Behind it, machine learning models detect anomalies, predict maintenance, and coach your driving. When something is wrong, a professional PDF report generates with charts and plain-English explanations you can hand to any mechanic.

The Seven Intelligence Layers

1. NervousSystem 3D Visualization: Tron-style dark scene (#0A0E17 background) with neon bloom. Engine pulses with RPM like a heartbeat. Coolant flows as animated particles. Electrical system propagates sparks. 40+ OBD-II parameters mapped to visual effects in real-time.

2. AccordMind Health Scoring: 0-100 composite score with subsystem breakdowns (Engine 30%, Transmission 20%, Fuel 15%, Cooling 15%, Exhaust 10%, Electrical 10%). Three-layer detection: EWMA statistical (<1ms), Isolation Forest every 30s (~5ms), trend regression every 5min. Learns YOUR car's baseline over 500 miles / 14 days.

3. Vibration Intelligence: Pixel 6 Pro's LSM6DSO IMU at 400 Hz + chassis-mounted MPU-6050 at 8 kHz. STFT and wavelet transforms detect tire imbalance (10-15 Hz), suspension degradation (1-15 Hz), engine misfire (RPM/60 Hz), and road quality. Convolutional autoencoder trained on "normal" driving flags deviations with AUROC near 1.0.

4. Engine Acoustic Diagnostics: $5 INMP441 MEMS microphone captures engine audio at 44.1 kHz. MFCC feature extraction + CNN classification detects misfires, belt wear, bearing noise, exhaust leaks, knock, and injector faults at 92%+ accuracy. Fused with OBD-II and vibration data through multi-modal autoencoder.

5. AI Driving Coach: Random Forest classifies driving style at 99-100% accuracy on OBD features. Spatial stereo audio cues through phone speakers (max 1 per 30s, suppressed during hard braking). Post-trip efficiency scoring. Route-specific learning with GPS geofencing. Financial savings tracking. 5-12% fuel savings proven by published research.

6. Digital Mechanic Reports: Professional PDF reports matching Snap-on/Autel format. Two-tier structure: customer-friendly summary with traffic-light indicators + detailed technical section with DTCs, freeze frames, trend charts, and spectrograms. Gemini Nano on Pixel 6 Pro generates natural language diagnostic summaries. Optional RAG with Honda service manual via ChromaDB + all-MiniLM-L6-v2.

7. Graph Neural Network: Car modeled as 8-node graph (Engine, Transmission, Exhaust, Cooling, Fuel, Electrical, Brakes, HVAC). 2-3 layer GCN with 64-dim embeddings (~200KB model, <10ms inference) detects cascading failures across subsystems that per-sensor detection misses. Visualized as interactive graph overlay on the 3D model.

Honda Mode 22 Proprietary

Transmission fluid temperature: PID 22 2201 at byte position 27. Formula: byte_value - 40 = °C. The 2026 Accord 1.5T uses Honda's CVT. Send raw ELM327 command 22 22 01 with header 7E0.

Extended coolant data: PID 01 67 returns dual sensor readings (engine block and radiator) at bytes 2 and 3, each using byte - 40.

Honda Sensing ADAS Limitation

ADAS data (adaptive cruise set speed, lead vehicle distance, LKAS status, collision mitigation) lives on a separate ADAS CAN bus that is NOT accessible through the OBD-II port. This requires a comma panda with a car harness to physically intercept the camera connection. Safety & Warranty // read-only guaranteed

OBD-II Reading is 100% Safe

Standard Mode 01 PID queries are read-only by design in the ISO 15031-5 standard. Writing to the ECU requires specific UDS services (WriteDataByIdentifier 0x2E, RoutineControl 0x31) that demand authenticated security access via seed/key exchange. This is impossible to trigger accidentally through a standard OBD adapter. In 10+ years of consumer OBD adapter usage, no documented case exists of a read-only adapter damaging a Honda ECU.

SafeOBDConnection Code Guard

The very first code written for this project is a command whitelist. Every byte that reaches the car passes through this gate. Even if Claude Code accidentally generates a write command, the safety filter blocks it:

ALLOWED_COMMANDS = {
    '01',  # Mode 01: Current data (read-only)
    '02',  # Mode 02: Freeze frame (read-only)
    '03',  # Mode 03: Read DTCs (read-only)
    '09',  # Mode 09: Vehicle info/VIN (read-only)
}

BLOCKED_COMMANDS = {
    '04',  # Clear DTCs (writes!)
    '08',  # Control onboard systems (writes!)
    '10',  # UDS diagnostic session
    '27',  # Security access
    '2E',  # Write data
    '31',  # Routine control
    '3E',  # Tester present
}

def send_command(self, cmd: str) -> Response:
    mode = cmd[:2]
    if mode not in ALLOWED_COMMANDS:
        raise BlockedCommandError(f"BLOCKED: {cmd}")
    return self._connection.query(cmd)

Battery Drain

WiCAN draws <1 mA in sleep mode. On a 50 Ah battery: 0.024 Ah per day. The car's own parasitic draw (25-50 mA) is 25-50x higher. WiCAN detects alternator voltage dropping below 13.5V and enters sleep automatically.

Warranty Protection

The Magnuson-Moss Warranty Act (15 U.S.C. §2301) explicitly protects consumers. Honda's own documentation states they cannot void a warranty solely because an aftermarket part has been used. They must prove the adapter caused the specific damage, which a read-only adapter cannot.

Physical Installation

No permanent modifications. OBD adapter plugs into port under dashboard. Pi secured with zip ties or industrial Velcro, away from airbag deployment zones. Phone on vent-clip mount. All cables routed with zip ties to prevent interference with pedals or steering. Everything unplugs in 2 minutes with zero trace.

CAN Bus Security

CAN has no authentication or encryption. Change WiCAN's default WiFi password immediately (default: @meatpi#). Use WPA2-PSK minimum on Pi's hotspot. Disable BLE when not configuring. Consider disabling WiCAN's AP entirely in production, using station mode exclusively.

SD Card Protection

OverlayFS enabled via raspi-config → Performance Options → Overlay Filesystem. Makes root filesystem read-only with in-RAM overlay. An automated test of 2,100+ power cuts across four Pi units showed zero corruption. Industrial SD card handles temps up to 85°C.

Biological Metaphor

Engine = Heart: Pulses red synchronized to RPM. 60 BPM at idle, faster at high RPM. engine.position.y = Math.sin(time * rpm/1000) * 0.002

Coolant = Circulatory: Animated particles along coolant paths. Blue-to-red gradient based on temperature. Speed proportional to flow rate.

Electrical = Nervous System: Propagating spark/pulse animations along wire-like paths. Brighter with higher voltage.

Transitions: 200-400ms ease-out curves. Idle ambient animations cycle at 2000-4000ms. Only critical alerts use dramatic animation.

Typography: 9mm+ for critical data (speed, RPM, health score). Max 5 visible data elements at any time. Use preattentive cues (color, size, motion) over text.

What AccordMind Can Predict

HIGH CONFIDENCE: Catalyst degradation (2-4 weeks lead). Fuel system issues from LTFT drift (1-4 weeks). Thermostat failure from warmup time analysis (should reach 82°C in 5-8 min). O2 sensor aging (2-8 weeks).

MODERATE: Alternator degradation from battery voltage under load trending down (days-weeks).

REQUIRES ADDITIONAL SENSORS: Brake pad wear, suspension degradation, tire condition. These need the vibration and audio layers.

Calibration

500 miles or 14 days, whichever comes first. Baselines maintained per ambient temperature bin using intake air temp PID: cold (<5°C), cool (5-15°C), mild (15-25°C), warm (25-35°C), hot (>35°C). This prevents false positives from seasonal variation.

2026 Honda Compatibility Note

Emerging reports from Honda HR-V forums indicate 2025-2026 Honda vehicles may have enhanced CAN bus security causing "no communication with ECU" errors on adapters using auto protocol detection. Workaround: manually select CAN protocol (ISO 15765-4, 11-bit, 500 kbaud). WiCAN's raw CAN access is protocol-agnostic and sidesteps this entirely.
